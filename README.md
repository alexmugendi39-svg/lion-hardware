# Lion Hardware - Isiolo Website

Static website - HTML + CSS + JS. No build step.

## Run locally
Open `index.html` in browser, or:
```
python -m http.server 8000
# open http://localhost:8000
```

## Deploy to Vercel
1. Push to GitHub
2. vercel.com -> New Project -> Import repo -> Deploy
3. No env vars needed - WhatsApp links use 0759 679 830

## Edit
- Phone: search `0759679830` in index.html / script.js
- Prices: edit product cards in index.html
- Bot answers: edit `botReply()` in script.js
